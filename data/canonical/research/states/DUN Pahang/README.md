# DUN Pahang — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Pahang.

## DUN (state assembly)
- **Seats:** 42
- **Latest election composition:** BN 17, PN 17, PH 8
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Pahang/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Pahang
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Pahang
- see `Report/states/DUN Pahang/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
