# DUN Terengganu — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Terengganu.

## DUN (state assembly)
- **Seats:** 32
- **Latest election composition:** PN 32
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Terengganu/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Terengganu
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Terengganu
- see `Report/states/DUN Terengganu/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
