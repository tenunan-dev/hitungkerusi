# DUN Sarawak — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Sarawak.

## DUN (state assembly)
- **Seats:** 82
- **Latest election composition:** GPS 76, PSB 4, PH 2
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Sarawak/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Sarawak
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Sarawak
- see `Report/states/DUN Sarawak/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
