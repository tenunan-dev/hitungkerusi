# DUN Kelantan — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Kelantan.

## DUN (state assembly)
- **Seats:** 45
- **Latest election composition:** PN 43, PH 1, BN 1
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Kelantan/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Kelantan
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Kelantan
- see `Report/states/DUN Kelantan/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
