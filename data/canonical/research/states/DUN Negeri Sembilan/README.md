# DUN Negeri Sembilan — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Negeri Sembilan.

## DUN (state assembly)
- **Seats:** 36
- **Latest election composition:** BN 18, PH 11, PN 7
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Negeri Sembilan/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Negeri Sembilan
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Negeri Sembilan
- see `Report/states/DUN Negeri Sembilan/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
