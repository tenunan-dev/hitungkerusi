# DUN Perlis — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Perlis.

## DUN (state assembly)
- **Seats:** 15
- **Latest election composition:** PN 14, PH 1
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Perlis/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Perlis
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Perlis
- see `Report/states/DUN Perlis/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
