# DUN Pulau Pinang — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Pulau Pinang.

## DUN (state assembly)
- **Seats:** 40
- **Latest election composition:** PH 27, PN 11, BN 2
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Pulau Pinang/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Pulau Pinang
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Pulau Pinang
- see `Report/states/DUN Pulau Pinang/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
