# DUN Selangor — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Selangor.

## DUN (state assembly)
- **Seats:** 56
- **Latest election composition:** PH 32, PN 22, BN 2
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Selangor/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Selangor
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Selangor
- see `Report/states/DUN Selangor/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
