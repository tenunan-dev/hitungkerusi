# DUN Perak — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Perak.

## DUN (state assembly)
- **Seats:** 59
- **Latest election composition:** PN 26, PH 24, BN 9
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Perak/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Perak
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Perak
- see `Report/states/DUN Perak/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
