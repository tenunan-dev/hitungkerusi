# DUN Sabah — State Election Data Hub

State Assembly (DUN) + federal parliamentary data for Sabah.

## DUN (state assembly)
- **Seats:** 73
- **Latest election composition:** WARISAN 25, GRS 22, BN 6, PBS 6, IND 6, UPKO 3, STAR 2, PN 1, KDM 1, PH 1
- `dun-election-results-latest.csv` — per-seat winners, party, bloc, votes, majority, turnout
- `dun-candidates-latest.csv` — all candidates (sex, ethnicity, age)
- see `Report/states/DUN Sabah/dun-election-summary.md` — readable results table

## Federal (parliamentary)
- `parliamentary-seats.csv` — federal seats within Sabah
- `voter-demographics.csv` — GE15 voter profile by constituency
- `ge16-battlegrounds.csv` — GE16 marginal seats (<5%) in Sabah
- see `Report/states/DUN Sabah/ge16-battleground-deepdive.md` — seat-by-seat GE16 analysis
