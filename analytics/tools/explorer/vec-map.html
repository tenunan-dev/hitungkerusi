🕸️ GE16 Vector Map

Real 384-dim MiniLM embeddings, projected to 2D via PCA (numpy SVD). Closeness = high cosine similarity = similar meaning. Each layer is projected independently.
How to read this: a point is one record's embedding (its meaning as a 384-d vector). Two points that are close together have high cosine similarity — the model considers them semantically related. Hover any point to see who/what it is. The projection is lossy (384-d → 2-d), so it shows broad clusters, not exact distances.
